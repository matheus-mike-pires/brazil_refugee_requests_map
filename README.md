# Refugee Request Flows in Brazil (1994–2026)

## About the Project

This repository provides a modular, Python-based analytical tool designed for researchers, policymakers, and the general public to access, process, and store data regarding refugee requests in Brazil. Utilizing public datasets from SISCONARE, the algorithm cleans and structures raw government records to perform quantitative policy impact analysis.

The codebase is built on Pandas for data manipulation and Matplotlib for data visualization. It automatically filters migration flows and calculates representation metrics across three distinct legislative eras:

* Pre-legislation (1994–2016)
* Implementation and transition (2017–2018)
* Post-legislation (2019–2026)

Users can generate global statistical overviews or filter by specific nationalities to output automated comparative charts (scatter plots, line graphs, and pie charts). This repository is actively maintained and will receive continuous updates as new government data becomes available.

## How to Run It

1. Download and unpack the **`complete_code_to_run.rar`** file located in the root directory.
2. Ensure Python is installed on your machine.
3. Install the required data science libraries by running `pip install pandas matplotlib` in your terminal.
4. Execute the main script to launch the interactive command-line interface.

## Structure Explanation

* **`0.drafts`**: Contains initial code versions used for versioning, debugging, and incremental algorithm updates.
* **`1.raw_data`**: Houses the full, unmodified database extracted from the Ministério da Justiça / Portal OBMigra. The original microdata for refugee requests can be verified at the [OBMigra Portal](https://www.gov.br/mj/pt-br/assuntos/seus-direitos/migracoes/portal-de-imigracao-laboral/obmigra-1/microdados/solicitantes_refugio/SolicitantesRefugio).
* **`2.scripts`**: Contains the main functional iterations of the analytical tool.
* `v1.0`: Command-line data processing and statistical engine (terminal-only, without Matplotlib rendering).
* `v2.0`: Final optimized architecture featuring dynamic Matplotlib integration and data leak corrections.


* **`3.test`**: Stores output examples and graphic visualizations (e.g., scatter plots, pie charts) generated by the algorithm's plotting engine during testing.
* **`Root`**: Contains this `README.md` documentation and the `complete_code_to_run.rar` executable package containing all necessary modules to run the application locally.
